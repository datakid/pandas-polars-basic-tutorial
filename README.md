# Pandas and Polars

Side-by-side tutorial for Pandas 3.0 and Polars 1.42. It has 21 sections, from installation to choosing between the two libraries.

## What it does

- Shows the same task in Pandas and in Polars, section by section: creating DataFrames, reading and writing data, selecting and filtering, transforming columns, sorting and ranking, group-by, window functions, pivots, joins, deduplication, types, categoricals, apply, missing data, strings, and dates and times.
- Has sections for what is new in Pandas 3.0, the Polars lazy API and streaming, interoperability, and when to use which.
- Switches between Both, Pandas and Polars views, and copies any code block.
- Searches with Ctrl+K or ⌘K, with the arrow keys, Enter and Esc to move through results.
- Records the versions it was written against: Pandas 3.0.4 and Polars 1.42.1, updated July 9, 2026.

## What it does not do

- It shows code and does not run it.
- It covers the two library versions above. Later releases can differ.
- It is a single page in English. The theme is kept in `localStorage` under `theme`.

## Network and install

Loads Google Fonts. It makes no other requests. Not installable; no service worker.

## Built with

One HTML file, with no build step, no framework and no libraries.

## Run locally

Open `index.html` in a browser, or serve the folder with any static file server.
